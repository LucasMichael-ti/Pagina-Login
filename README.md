🔐 DevLucas Login

Uma interface de tela de login web desenvolvida com HTML5 e CSS, criada com o objetivo de praticar desenvolvimento front-end, estruturação de páginas e criação de interfaces modernas e responsivas.

📌 Sobre o projeto

O DevLucas Login é uma página de autenticação com uma interface simples, moderna e organizada.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em Tecnologia da Informação e Desenvolvimento Web, colocando em prática conceitos de HTML e CSS.

✨ Funcionalidades

* 🔑 Campo para usuário/e-mail
* 🔒 Campo para senha
* ☑️ Opção de lembrar o acesso
* 🔄 Recuperação de senha
* 📝 Opção de cadastro
* 📱 Interface responsiva
* 🎨 Layout moderno e organizado

🛠️ Tecnologias utilizadas

* HTML5 — estrutura e organização da página
* CSS3 — estilização, layout e responsividade

O principal objetivo deste projeto é desenvolver e aprimorar conhecimentos em desenvolvimento front-end, praticando a criação de interfaces, organização de código e conceitos de responsividade.
